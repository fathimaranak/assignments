# Fathima Rana K Resume (Node.js + Express)

This project keeps Rana's original HTML resume content and CSS design. Express is used only to serve the files.

## Run locally
1. Install Node.js (18 or newer).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm start`.
5. Visit http://localhost:3000.

Resume files are in `public/index.html` and `public/style.css`.
