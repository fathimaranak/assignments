# Assignment 6 - Personal Website (Node.js + Express)

This project keeps the original personal website pages and styling, and uses Node.js with Express to serve them locally.

## Run locally

1. Open this folder in VS Code.
2. Open a terminal in this folder.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   npm start
   ```

5. Visit http://localhost:3000 in your browser.

The original website pages are in `public/`:
- `index.html`
- `about.html`
- `contact.html`
- `css/style.css`

`node_modules` is intentionally excluded from Git. Commit `package.json` and `package-lock.json` (if generated), not the installed dependencies.
